# Assets and licences

Rule: only original work or clearly free assets (CC0, SIL OFL, etc.).
Every file under `Assets/Art` and `Assets/Audio` must be listed here with
its source and licence **before** it is committed.

## Assets currently in the project

| File | Source | Licence |
|------|--------|---------|
| *(none)* | All shapes (stars, circles, letter guide lines) are generated by code at runtime (`SpriteFactory.cs`) or stored as point data in `letters.json`. Letter stroke data was written by hand for this project. | Original (project's own) |

No pictures, fonts or sounds are included yet. The game works without them
(coloured placeholder cards, silent audio, romanized labels).
